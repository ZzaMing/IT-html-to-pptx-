## 📌 프로젝트 개요

본 프로젝트는 삼육대학교 IT 해외봉사단이 베트남 다낭 교원대학교 학생들을 대상으로 진행한 **10일 완성 웹 프로그래밍(HTML·CSS·JS) 교육 및 문화 교류 활동**의 성과를 보고하기 위해 제작된 고품질 프레젠테이션 덱입니다.

- **파견 기관**: 월드프렌즈코리아(WFK) IT봉사단
- **교육 대상**: 베트남 다낭 교원대학교 학생 (비전공자 및 초심자)
- **교육 내용**: Semantic HTML 구조화, CSS/Flexbox 레이아웃, JavaScript 동적 인터랙션, 자기소개 웹사이트 프로젝트
- **협업 시너지**: 컴퓨터공학부 3인(교육·실습 멘토링) + 항공관광외국어학부 1인(통역·라포 형성)

## 🚀 시작하기 및 빌드 방법

본 프레젠테이션은 **[Marp CLI](https://marp.app/)**를 기반으로 모듈형 마크다운(slides/*.md) 및 최신 반응형 HTML/CSS로 구축되었습니다.

### 1. 사전 요구사항
- [Node.js](https://nodejs.org/) (v16 이상 권장)

### 2. 빌드 명령어
```bash
# 슬라이드 머지 및 웹 프레젠테이션(index.html) 빌드
npm run build

# 파워포인트(PPTX) 파일 생성
npm run pptx

# 제출용 고화질 PDF 파일 생성
npm run pdf

# 전체 일괄 빌드 (HTML + PPTX + PDF)
npm run build:all

# 마크다운 수정 실시간 감지 (Live Watch 모드)
npm run watch
```
